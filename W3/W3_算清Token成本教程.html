W3 任务三 · 算清楚 Token 成本教程

目标：做一张表，列清每个功能的「输入/输出 token + 单价」，算出月成本　·　记录日期：2026-10-20

一、先把"token"想明白

模型不是按"字"收费，是按"token"收费。token 是模型眼里的最小计量块——可以是一个词、一个数字、一个标点，中文里大约 1~2 个汉字 = 1 个 token（粗略记：1 token ≈ 1 字多）。

用硬件工程师的话说：token 就像零件的"最小计量单位"（比如"颗"），不是"个"。

一次调用 = 进料（输入 token）＋ 出料（输出 token），各自乘单价

＝ 上料用了多少料 × 进料价　＋　产出用了多少料 × 出料价

所以"成本"这件事，本质就是给 API 调用主线（W3 任务一）的每一步都贴上价签。

二、核心公式（请照着验算，别直接信）

单次调用成本 = 输入token × 输入单价 ＋ 输出token × 输出单价

月成本       = 单次调用成本 × 月调用次数
             （也等于：月输入token总量 × 输入单价 ＋ 月输出token总量 × 输出单价）

单价单位   = 元 / 百万 token
             → 计算时务必换算：单价 = 标称价 ÷ 1,000,000

验算小样（照抄一遍你就懂了）：输入 1000 token、输出 500 token，输入价 3 元/百万、输出价 16 元/百万。

单次 = 1000 × (3 ÷ 1,000,000) ＋ 500 × (16 ÷ 1,000,000)
     = 0.003 ＋ 0.008 ＝ 0.011 元/次
月成本（调用 1000 次）= 0.011 × 1000 ＝ 11 元

表头九列，各是什么

  • 功能：你工作流里的每个场景（总结、问答、翻译、抽取…），一个功能一行
  • 模型：这个功能用哪个模型（省钱/省钱模型分开列，因为它们单价差很多）
  • 平均输入/输出 token：实测几次取平均（别瞎估，见第五节怎么取）
  • 输入/输出单价：查官网"元/百万 token"，注意输入和输出通常是两个价
  • 单次成本：用第二节公式算
  • 月调用次数：你估计这功能一个月跑多少次
  • 月成本：单次 × 次数

四、拿你自己的"文本总结"工作流算一笔（实锤）

你那个工作流配置：model = doubao-seed-2-0-pro，thinking = disabled。按 2026-10 官网最短输入档单价：输入 3.2 元/百万、输出 16 元/百万。

一句文本约 50 token 进，摘要约 40 token 出：

单次 = 50×3.2/1e6 ＋ 40×16/1e6 ＝ 0.00016 ＋ 0.00064 ＝ 0.0008 元（约 0.8 厘/次）
月调用 1000 次 → 0.8 元/月

结论很直观：这种"短进短出"的轻量功能，几乎不花钱，月成本在"毛"级。真正烧钱的是"长进长出"——比如第②行长文档问答，一下子就到 20 元/月。

五、真实 token 数从哪来（别瞎估）

  • 扣子编程：对话/运行结果里会显示「积分消耗」，反向可推 token（或看 usage）
  • 直接调 API：响应里带 usage.prompt_tokens（输入）和 usage.completion_tokens（输出），最准
  • 没接 API 时：同一功能手动跑 3~5 次，看字数量级 × 1.5（中文粗略）取平均

六、五个坑（算漏一个，月成本能差几倍）

坑说明对你的影响
① 输入≠输出价输出单价通常是输入的 2~5 倍只算一个价会严重低估（你那个 16 vs 3.2，输出贵 5 倍）
② 思考模式吃 token开 thinking 会额外产生"推理 token"你设了 thinking=disabled，是对的——总结不该开
③ 输入越长越贵豆包按输入长度分档，最长档≈最短档的 3 倍长上下文（第②行）要单独估，不能套短文本单价
④ 缓存命中更便宜相同前缀反复调用，命中缓存单价低至 1/5批量雷同任务（第④行）用缓存能省不少
⑤ 峰谷定价DeepSeek 高峰价≈低谷的 2 倍，周末全低谷批量任务挪到低谷/周末跑，立省一半
价格口径提醒 ❓：本教程单价取自 2026-10-20 各官网（豆包火山方舟、DeepSeek API 文档）的最短输入档。 模型厂商会调价、且按输入长度分档，真实数字请以你跑任务当天的官网价格页为准。 方法是铁打的，数字是流水的——掌握算法比背价格重要。

七、自查三问（能答出即过关）

  • "单次 0.0008 元"是怎么算出来的？
    答：50×3.2÷1,000,000 ＋ 40×16÷1,000,000 ＝ 0.0008
  • 为什么"长文档问答"比"短句翻译"贵那么多？
    答：输入 token 量级差几百倍（8000 vs 30），而输出价又是输入的几倍，相乘放大
  • 想再省一半，最该调哪个旋钮？
    答：① 关 thinking；② 换更便宜的小模型（Mini/Lite）；③ 批量挪到低谷或开缓存命中
