W3 任务四 · 做 3 个自动化教程 · 扣子网页版

目标：① 消息/邮件 → AI 摘要 → 归档　② 日报素材自动汇总　③ 文档批量格式转换　·　记录日期：2026-10-20
先回答你的疑问：任务四是不是"做工作流"？
是。但它 = 工作流 + 触发器 + 收尾落地。任务二你跑通的那条"文本总结"只差这两端——加上"什么时候跑"和"结果存哪"，它就是个自动化了。所以你任务二的手艺（节点、prompt、json 配置）全部能复用。

一、自动化是什么（硬件比喻）

把"人手动点 N 步"变成"触发一次自己跑完"。想象一条产线：

开关（触发器）→ 工位1 取料→ 工位2 AI 质检/加工→ 工位3 …→ 成品入库（落地）

触发器 = 传送带开关（定时 / 收到事件）；工位 = 工作流节点；入库 = 写库 / 发消息 / 存文件。

二、三个自动化的"节点图"

① 消息 / 邮件 → AI 摘要 → 归档

定时 / 新邮件事件→ 读取邮件或消息→ 大模型摘要（复用任务二）→ 写入归档表 / 知识库

扣子实现要点：

  • 触发器：编排页找「触发器 / 定时」入口，选"定时每 30 分钟"或"邮件/消息事件"（❓ 具体按钮名随 3.0 UI 略有差异，认准"触发"二字）
  • 读取：用邮件/即时消息的连接器或插件节点拉内容（没有就加一个 HTTP 节点调你自己的接口）
  • 摘要：直接把任务二那个 summarize 节点接进来，不用重写
  • 归档：用「写入数据表」或「写入知识库」节点，把 summary 存下来

② 日报素材自动汇总

每天 18:00（定时）→ 拉取多来源（消息/笔记/项目）→ 大模型归纳成日报→ 发到群 / 写入文档

扣子实现要点：

  • 触发器：定时 cron 每天 18:00（扣子里一般叫"定时触发"）
  • 多来源：多个"读取"节点并行，把各自内容拼成一个大输入
  • 归纳：大模型节点 sp 里写死日报模板（"按 今日进展/风险/明日计划 三段输出"），这样每次格式统一
  • 落地：发到指定群聊，或写入一篇共享文档

③ 文档批量格式转换

手动 / 新文件落入目录→ 列出待转换文件清单→ 循环：逐个转换→ 输出到目标目录

扣子实现要点 + 一个重要提醒：

  • 批量 = 一个循环 / 批处理节点，对清单里每个文件跑一遍转换逻辑
  • 转换逻辑：用一个代码节点（写 python，调用转换库），或装一个转换插件
  • ⚠️ 别误会：你之前那个本地 doc2docx 工具是靠本机 Word 转的，扣子云端摸不到你电脑上的 Word。所以云端版要改用"代码节点调用转换库（如 python-docx / LibreOffice 命令）"，不能把本地工具直接搬上去
  • 务实建议：你自己的 .doc 批量转 .docx，本地那个 doc2docx 工具其实最顺手；扣子这条自动化更适合"云端文件（已上传到云存储）批量转"的场景

三、通用五步搭法（三个都适用）

步动作在扣子里怎么做
1定触发器编排页加「触发器」：定时 / 事件（新邮件、新文件…）
2拉输入连接器的"读取"节点，或 HTTP 节点调你自己的接口
3接 AI 处理复用任务二 summarize 节点，或新加大模型节点（写好 sp/up）
4收尾落地「写入数据表 / 知识库 / 发消息 / 写文档」节点
5试运行 + 定时先点试运行确认链路通，再开触发器让它自动跑

四、和任务二、任务三的关系（串联起来）

  • 任务二给了你"AI 处理"这个核心节点——三个自动化全都复用它
  • 任务三的 token 成本表，直接能算这三个自动化的月花费：月成本 = 单次成本 × 月触发次数。比如日报每天 1 次、30 天，把长文档那种"单次 0.04 元"×30 ≈ 1.2 元/月，几乎可忽略

五、五个坑

坑说明
① 触发器没配就以为"自动化好了"只搭工作流不算自动化，必须接触发器 + 开"启用"，否则永远等你手动点
② 邮件/消息权限没授权连接器要你先登录授权，没授权读取节点会报错
③ 批量转换没设"失败跳过"一个坏文件卡住会让整批失败；循环节点要配"出错继续"
④ 忘记算触发频率的成本定时每 5 分钟跑一次，一天就 288 次——用任务三公式乘一下，别被累积吓到
⑤ 把本地工具当云端用如③所说，本机 Word 云端摸不到；云端自动化要改用代码节点/插件
数据红线（和前几篇一致，这里最要命）：① 和 ② 会碰你的邮件、消息、公司内部资料。这些若走扣子纯云端，等于把内容交给云端处理——公司专有 / EMC 案例 / 客户信息不要喂。练手用个人无关内容。真要处理公司数据，要么本地部署（任务二提过的 Dify 本地），要么确认平台有合规数据协议。

六、自查三问（能答出即过关）

  • 任务四和任务二的区别是什么？
    答：多了"触发器"（什么时候跑）和"落地"（结果存哪）。中间 AI 处理一样。
  • 日报自动化为什么"定时 18:00 + 固定模板"最稳？
    答：定时保证每天跑；固定 sp 模板保证输出格式统一、可归档。
  • 文档批量转换，为什么不能直接搬你本地 doc2docx 工具？
    答：扣子云端访问不到你本机 Word；要用代码节点调转换库或装插件。
关联：本任务 = 任务二（核心节点）× 任务三（成本估算）的落地延伸。
平台：扣子网页版（coze.cn）/ 扣子编程。触发器入口名称随 3.0 UI 微调，以你界面实际按钮为准（标 ❓ 处）。
数据红线不变：邮件/公司/EMC 专有资料勿喂云端。
